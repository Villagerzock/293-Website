# Personal Website Projekt

Statisches HTML/CSS-Projekt passend zum M293-Auftrag.

## Enthaltene Seiten
- `index.html` – Über mich
- `skills.html` – Fähigkeiten
- `portfolio.html` – Portfolio mit Galerie und Video-Platzhalter
- `contact.html` – Kontaktseite mit Kontaktformular

## Anforderungen
- HTML & CSS
- Keine Inline-Styles ausser Prozentwerte für Skill-Balken
- Responsive Layout für Desktop, Tablet und Smartphone
- Durchgängige Navigation
- Durchgängiges Farbkonzept
- Durchgängige Schriftart
- Bilder als SVG-Platzhalter
- Video-Platzhalter im Portfolio

## Veröffentlichung
Das Projekt kann direkt in ein öffentliches GitHub-Repository hochgeladen und über GitHub Pages veröffentlicht werden.
